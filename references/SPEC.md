# 스펙 · 표본 · 대표성

> **이 문서를 먼저 읽는다.** 이 스킬이 무엇을 보장하고 무엇을 보장하지 않는지가 여기 있다.
> 결과를 해석하거나 남에게 보고할 때 이 한계를 함께 전달한다.

| 성격 | **합성 데이터.** 실존 인물이 아니다 |

### 이 데이터에 **없는** 것

아래는 필드로 존재하지 않는다. **추정해서 채우지 않는다.**

- **소득 · 자산 · 구매력** ← 가장 큰 제약
- 디지털 숙련도 수치
- 성격 지표(OCEAN 등)
- 건강 지표

> **소득이 없다는 점이 이 스킬의 가장 큰 제약이다.**
> 5번 질문(지불 능력)과 R4(지불 여력 차이) 판정은 **소비 서술에서 읽은 추정**이다.
> 리포트에 반드시 명시한다.

## 3. 대표성 — 보장하지 않는 것

### 통계적 대표성이 없다

세 겹으로 없다.

1. **원본이 합성 데이터다.** 공식 통계에 *정렬* 됐을 뿐, 실제 인구를 조사한 표본이 아니다.
2. **L1은 사람이 골라 담은 목적 표집이다.**
3. **L2는 편의 표집에 가깝다.**

### 절대 하면 안 되는 것

| 금지 | 왜 |
|---|---|
| **"고객의 40%가 재구매합니다"** | 비율 추정 불가 |
| **"이 가격이면 X%가 삽니다"** | 소득 필드 자체가 없다 |
| **"CLV는 480만 원입니다"** | 이 스킬은 CLV **구간**을 판정할 뿐, 금액을 계산하지 않는다 |
| **"통계적으로 유의합니다"** | 유의성 검정의 전제가 성립하지 않는다 |
| A/B 테스트 대체 | 실제 트래픽 실험을 대신할 수 없다 |
| 실제 고객 인터뷰 대체 | 전 단계일 뿐이다 |

### 이 스킬이 실제로 잘하는 것

| 할 수 있는 것 | 왜 유효한가 |
|---|---|
| **거절 이유의 종류 수집** | 종류(what)는 잡힌다. 빈도(how many)는 못 잡는다 |
| **닮은꼴 누수 지점 발견** | 한 명이 그 이유로 거절하면 그 이유는 실재한다 |
| **1회성 신호 감지** | 6번 질문에서 재구매 여지가 갈린다 |
| **놓친 관점 노출** | 나와 다른 조건의 사람이 무엇을 먼저 보는지 |
| **용어·카피 오해 탐지** | 오해는 한 건만 나와도 증거다 |
| **실제 인터뷰 전 질문 설계** | 무엇을 물어야 할지가 좁혀진다 |

> **한 줄 요약** — 이 스킬은 **"몇 %인가"에 답하지 않는다. "무엇을 놓쳤는가"에 답한다.**

### CLV 판정의 성격

**이 스킬은 CLV 금액을 계산하지 않는다.** 네 구간 중 어디인지만 판정한다.

```
찐팬 후보 / 반복 고객 / 1회성 / 응원단
```

금액 계산은 **사용자가 자기 객단가와 유지 기간 가정으로** 따로 한다.
페르소나가 계산해주지 않는다.

### 결과를 보고할 때 붙일 문장

> *이 결과는 공식 통계에 정렬된 합성 페르소나 N명을 대상으로 한 정성 조사입니다.
> 확률 표본이 아니므로 비율·빈도로 해석할 수 없으며, 실제 고객 검증을 대체하지 않습니다.
> 지불 능력 판정은 소비 서술에서 읽은 추정이며 소득 데이터가 아닙니다.
> 데이터: NVIDIA Nemotron-Personas-Korea (CC BY 4.0)*

## 4. 표본 크기

| 무엇 | 권장 | 이유 |
|---|---|---|
| **한 세션 패널** | **5명** (고CLV2·저CLV1·닮은꼴2) | 더 늘려도 새 발견보다 중복이 빨리 는다 |
| **닮은꼴 전용 세션** | **4명** | R유형을 네 개까지 커버 |
| **QA 패널** | **3명** | 단계별 추적이라 인원이 많으면 리포트가 무너진다 |
| **후보 풀(L2)** | **1,500~5,000명** | 조건에 맞는 5명을 뽑을 수 있으면 충분 |

풀을 키우는 건 **정확도가 아니라 적중률**을 위해서다.
