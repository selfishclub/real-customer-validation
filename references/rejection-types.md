# 닮은꼴 거절 6유형

> **닮은꼴 = 광고 타게팅 필터에 걸리는데, 안 사는 사람.**

---

## 왜 이 자리를 따로 두나

**명백한 비고객은 안전한 오답이다.** 애초에 타게팅 필터에 안 걸리니 광고비가 안 샌다.

**진짜 위험한 건 조건표상 우리 고객과 똑같이 생겼는데 안 사는 사람이다.**

| | 고CLV 1 | 닮은꼴 1 |
|---|---|---|
| 나이 | 38 | 37 |
| 지역 | 서울 | 서울 |
| 직군 | 사무직 | 사무직 |
| 소득 추정 | 중상 | 중상 |
| **결과** | **산다** | **안 산다** |

조건표가 거의 같다. 그런데 결과가 반대다.
**광고를 태우면 예산이 정확히 오른쪽으로 샌다.**

---

## 선정 규칙

1. **인구 조건은 타깃과 일치시킨다.** 나이·성별·지역·직업군·소득 추정
2. **거절 사유는 서술에서 찾는다.** 아래 6유형 중 하나에 해당하는 서술을 가진 사람
3. **두 명은 서로 다른 유형으로.** 같은 유형 둘은 정보량이 반이 된다
4. **명백한 비고객을 넣지 않는다.** 그건 이 자리의 목적이 아니다

---

## R1 · 이미 해결됨

**정의** — 같은 문제를 이미 다른 것으로 해결하고 있다.

| | |
|---|---|
| **어떤 서술을 찾나** | 대체재를 이미 쓰고 있는 서술. 루틴이 자리잡은 서술 |
| **전형적 발화** | *"그거 지금 OO로 하고 있어요"* / *"굳이 바꿀 이유가…"* |
| **오해하기 쉬움** | 관심이 없다고 읽기 쉽다. 사실은 **이미 충족**된 것 |
| **처방** | **대체 지점을 한 줄로.** 무엇이 더 나은지가 명확하지 않으면 안 움직인다 |

> 이 유형이 많으면 **경쟁 상대를 잘못 보고 있다는 뜻**이다.
> 진짜 경쟁자는 동종 업체가 아니라 그 사람이 지금 쓰는 것이다.

---

## R2 · 우선순위 낮음

**정의** — 문제는 인정하는데 지금 급하지 않다.

| | |
|---|---|
| **어떤 서술을 찾나** | 더 급한 관심사가 뚜렷한 서술 (이사·육아·이직·건강 등) |
| **전형적 발화** | *"필요하긴 한데 지금은 아니에요"* / *"나중에요"* |
| **오해하기 쉬움** | *"나중에"* 를 긍정 신호로 읽기 쉽다. **거의 오지 않는다** |
| **처방** | **트리거를 찾는다.** 언제 급해지는지. 그 시점에 맞춰 다시 만난다 |

> 이 유형에게 할인은 안 통한다. **시점의 문제**지 가격의 문제가 아니다.

---

## R3 · 결정권 없음

**정의** — 쓰는 사람과 사는 사람이 다르다.

| | |
|---|---|
| **어떤 서술을 찾나** | 가족·조직의 결정 구조가 드러난 서술. 3세대 동거, 배우자 합의, 팀장 승인 |
| **전형적 발화** | *"제가 정할 수 있는 게 아니라서요"* / *"남편이랑 상의해봐야"* |
| **오해하기 쉬움** | **가장 많이 놓치는 유형.** 본인이 좋다고 하니 타깃이 맞다고 착각한다 |
| **처방** | **구매자용 메시지를 따로 만든다.** 사용자를 설득하는 말과 결제자를 설득하는 말은 다르다 |

> B2B, 아동·시니어 대상, 고가 상품에서 특히 자주 나온다.
> *"좋다"* 와 *"산다"* 사이에 한 사람이 더 있다.

---

## R4 · 지불 여력 차이

**정의** — 인구 조건은 같은데 돈의 사정이 다르다.

| | |
|---|---|
| **어떤 서술을 찾나** | 같은 직업군인데 소비가 보수적인 서술. 부양 부담, 대출, 십 원 단위 정산 |
| **전형적 발화** | *"좋은데 그 가격은 좀…"* / *"조금 더 저렴한 건 없나요"* |
| **오해하기 쉬움** | **두 번째로 많이 놓친다.** 직업·지역이 같으면 지불 능력도 같다고 가정한다 |
| **처방** | **가격대를 나누거나, 이 층은 포기한다** |

> ⚠️ **데이터에 소득 필드가 없다.** 이 판정은 소비 서술에서 읽은 추정이다.
> 리포트에 반드시 명시한다.

> **포기도 답이다.** 모두를 잡으려 하면 아무도 못 잡는다.

---

## R5 · 전환 비용

**정의** — 새것이 더 나은 건 알지만, 기존 것을 버리는 비용이 크다.

| | |
|---|---|
| **어떤 서술을 찾나** | 기존 습관·도구에 오래 정착한 서술. 단골, 장기 이용, 축적된 기록 |
| **전형적 발화** | *"지금 쓰는 걸 두고 갈아타긴 좀"* / *"다니던 데가 있어서요"* |
| **오해하기 쉬움** | 제품이 부족하다고 읽기 쉽다. 사실은 **이동 비용**의 문제 |
| **처방** | **이전 비용을 우리가 낸다.** 데이터 이관 지원, 병행 기간, 첫 달 무료 |

> 제품을 더 좋게 만들어도 안 움직인다. **옮기는 수고를 줄여야** 움직인다.

---

## R6 · 카테고리 불신

**정의** — 이 종류 전체를 안 믿는다.

| | |
|---|---|
| **어떤 서술을 찾나** | 회의적·검증 지향 성격 서술. 리뷰를 꼼꼼히 보는, 약관을 읽는 |
| **전형적 발화** | *"그런 거 다 비슷하던데요"* / *"광고는 다 그렇게 말하죠"* |
| **오해하기 쉬움** | 우리 브랜드를 못 믿는다고 읽기 쉽다. **카테고리 전체**에 대한 불신이다 |
| **처방** | **증거를 앞에 둔다.** 카테고리 설명이 아니라 결과. 숫자·전후·제3자 |

> 이 유형에게 *"저희는 다릅니다"* 는 안 통한다. 다 그렇게 말하기 때문이다.

---

## 판정이 애매할 때

| 헷갈림 | 판정 기준 |
|---|---|
| **R1 vs R2** | 이미 하고 있으면 R1, 아직 안 하고 있으면 R2 |
| **R2 vs R4** | 시점의 문제면 R2, 금액의 문제면 R4 |
| **R3 vs R4** | 못 정해서면 R3, 못 내서면 R4 |
| **R4 vs R5** | 돈이 없어서면 R4, 이미 낸 게 아까워서면 R5 |
| **R5 vs R1** | 옮기기 귀찮으면 R5, 지금 걸로 충분하면 R1 |
| **R6 vs 전부** | 우리를 못 믿으면 다른 유형, **이 종류를 못 믿으면 R6** |
