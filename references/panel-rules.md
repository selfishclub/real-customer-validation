# 패널 구성 규칙

> 누구에게 묻느냐가 무엇을 묻느냐보다 먼저다.

---

## 1. 기본 패널 — 5인

**사는 쪽 3명 + 안 사는 쪽 2명.**

| 자리 | 산다? | 다시 온다? | 선정 조건 | 무엇을 잡나 |
|---|---|---|---|---|
| **고CLV 1** | O | O | 마음·돈·시간 다 있음 | 찐고객이 맞는지 |
| **고CLV 2** | O | O | 위와 동일, 다른 지역·직군 | 개인차인지 확인 |
| **저CLV 1** | O | **X** | 마음·돈 있으나 **재구매 여지 없음** | **1회성으로 끝날 신호** |
| **닮은꼴 1** | **X** | — | 타깃 조건 일치, R1~R6 중 하나 | 예산 누수 지점 |
| **닮은꼴 2** | **X** | — | 위와 **다른 R유형** | 두 번째 누수 지점 |

### 세 그룹을 헷갈리지 않는다

- **저CLV 1은 안 사는 사람이 아니다.** 이 사람은 **산다.** 다만 한 번만 산다.
- **닮은꼴 1·2가 "조건은 맞는데 안 사는 사람"이다.** 둘 다 그렇다.
- **명백한 비고객은 부르지 않는다.** 안전한 오답이라 아무것도 안 알려준다.

### 저CLV 자리가 왜 필요한가

1회성 고객과 찐고객은 **1~5번 질문에서 구분되지 않는다.**
둘 다 "살 것 같다"고 답한다. **6번에서만 갈린다.**

이 자리가 없으면 리포트에서 둘이 똑같이 O로 나온다.

## 2. 모드별 인원

| 모드 | 인원 | 구성 |
|---|---|---|
| **살까, 안 살까** | 5명 | 기본 구조 |
| **한 번인가, 계속인가** | 5명 | 기본 구조 (6·7번에 시간 배분) |
| **걸리는데 왜 안 사나** | **4명** | **닮은꼴만 4명, 서로 다른 R유형** |
| **3초 안에 이해되나** | 5명 | 기본 구조 |
| **이 가격이면 사나** | 4명 | 고CLV 2 · 저CLV 1 · 닮은꼴(R4) 1 |
| **어디서 막히나** | 3명 | 고CLV 1 · 저디지털 1 · 회의적 1 |
| **실제로 눌러보면** | 1~2명 | 한 번에 한 명씩 |

## 3. 선정 절차

### 확장 팩(L2)이 있을 때

```
1. 타깃 조건을 항목으로 분해   → 나이대 / 성별 / 직업군 / 지역 / 태그
2. 쿼리 3발
   - 고CLV : 전 조건 AND + 재구매 여지 있는 서술   → 2명
   - 저CLV : 전 조건 AND + 1회성 성격 서술         → 1명
   - 닮은꼴 : 전 조건 AND + R유형 서술              → 2명 (서로 다른 유형)
3. 후보가 많으면 다양성 우선 (같은 직업·지역 중복 회피)
4. 후보가 없으면 조건을 한 단계씩 완화하고 그 사실을 보고
```

### 코어 팩(L1)만 있을 때

35명뿐이라 전 조건 일치가 거의 안 나온다. **근사치를 쓰되 격차를 명시한다.**

```
각 페르소나 소개에 [격차] 한 줄 필수:
"타깃과 다른 점 — 직업이 부동산 영업이 아니라 보험 상담입니다"
```

**절대 금지** — 페르소나에게 없는 직업·경험·취향을 씌우는 것.
그 순간 통계 근거가 사라지고 그냥 지어낸 인물이 된다.

## 4. 패널 스냅샷 — 재현성

쿼리로 매번 뽑으면 사람이 바뀌어서 **수정 전후 비교가 불가능하다.**

```markdown
## 패널 스냅샷 — (프로젝트명)
- 생성일: YYYY-MM-DD
- 타깃 정의: (한 줄)
- 소스: 코어팩(L1) / 확장팩(L2)

| 자리 | ID | 이름 | 나이·성별 | 직업 | 지역 | R유형 |
|---|---|---|---|---|---|---|
| 고CLV1 | … | … | … | … | … | — |
| 닮은꼴1 | … | … | … | … | … | R4 |
```

**같은 프로덕트를 다시 테스트하면 반드시 같은 패널을 쓴다.**
사람이 바뀌면 카피가 통한 건지 사람이 달라진 건지 구분할 수 없다.

## 5. 세그먼트 (코어 팩)

| 코드 | 세그먼트 | 인원 |
|---|---|---|
| **A** | 2030 싱글·직장인·취준 | 10 |
| **B** | 3040 부모·가족 중심 | 6 |
| **C** | 1인 사업자·자영업·전문직 | **5** |
| **D** | 4050 직장인·전문직 | 6 |
| **E** | 5060+ 시니어·저디지털 | 8 |

> **C가 가장 얇다(5명).** 1인 사업자가 타깃이면 코어 팩만으로는 부족하다.

## 6. 타깃이 없을 때

**후보를 열어주되 최종 선택은 사용자가 한다.**

```
이 프로덕트라면 이런 분들이 먼저 떠올라요:
① …
② …
③ …

어느 쪽으로 갈까요? 다른 타깃이 있으면 그걸로 가도 됩니다.
```

**확인 없이 ①로 진행하지 않는다.**
