# real-customer-validation

> **찐고객 = 이 사람이 있어서 비즈니스가 굴러가는 고객.**
> 많이 쓰는 사람이 아니라, **오래 남는 사람**입니다.

세운 가설이 맞는지 **통계에 물린 한국인 페르소나**에게 물어 검증하는 Claude 스킬입니다.

---

## 살 사람과 안 살 사람을 함께 부릅니다

**패널 5명 = 사는 쪽 3명 + 안 사는 쪽 2명**

| 자리 | 산다? | 다시 온다? | 무엇을 잡나 |
|---|---|---|---|
| **고CLV 1** | O | O | 찐고객이 맞는지 |
| **고CLV 2** | O | O | 개인차인지 확인 |
| **저CLV 1** | O | **X** | **한 번 사고 끝날 신호** |
| **닮은꼴 1** | **X** | — | 예산 누수 지점 |
| **닮은꼴 2** | **X** | — | 다른 유형의 누수 |

### 세 그룹을 헷갈리지 마세요

- **저CLV 1은 안 사는 사람이 아닙니다.** 이 사람은 **삽니다.** 다만 한 번만 사요.
- **닮은꼴 1·2가 "조건은 맞는데 안 사는 사람"입니다.** 둘 다 그렇습니다.

---

## 닮은꼴 — 광고 타게팅에 걸리는데 안 사는 사람

**"조건이 맞다"의 정확한 뜻은 이겁니다.**

> **광고 타게팅 필터에 걸리는 사람.**

나이·지역·직업군·소득 추정으로 필터를 돌리면 **화면에 나오는 사람**입니다.
그런데 실제로는 안 삽니다. **그래서 예산이 샙니다.**

명백한 비고객은 애초에 필터에 안 걸리니 돈이 안 새요. **닮은꼴은 걸립니다.**

### 거절 6유형

| | 유형 | 왜 안 사나 | 처방 |
|---|---|---|---|
| **R1** | 이미 해결됨 | 다른 걸로 하고 있다 | 대체 지점을 한 줄로 |
| **R2** | 우선순위 낮음 | 급하지 않다 | 트리거를 찾는다 |
| **R3** | **결정권 없음** | 쓰는 사람 ≠ 사는 사람 | 구매자용 메시지 별도 |
| **R4** | **지불 여력 차이** | 조건은 같은데 돈 사정이 다르다 | 가격대 분리 or 포기 |
| **R5** | 전환 비용 | 기존 것 버리기가 아깝다 | 이전 비용을 우리가 |
| **R6** | 카테고리 불신 | 이런 종류를 안 믿는다 | 증거를 앞에 |

> **R3와 R4를 가장 많이 놓칩니다.** 둘 다 "타깃이 맞다"고 착각하기 딱 좋아요.

## 일곱 단계로 묻습니다

```
1. 첫 반응
2. 안 쓸 이유 — 최소 2가지          ← 아첨 차단
3. 그럼에도 쓴다면 언제
4. 지인에게 설명한다면
5. 이 가격을 낼 수 있나 · 결정권은 본인에게
6. 두 번째도 살 것 같나 · 언제쯤
7. 친구에게 데려갈 만한가
```

| 단계 | 무엇을 판별 |
|---|---|
| 1~4 | 마음 |
| **5** | **돈 축** — 응원단인가 찐고객인가 |
| **6** | **시간 축** — 1회성인가 반복인가 |
| **7** | **확산 축** — 찐팬 가능성 |

> **6번이 CLV의 실체입니다.**
> *"살 것 같다"* 와 *"두 번째도 살 것 같다"* 는 완전히 다른 답이에요.

### 거절만 듣는 게 아닙니다

**2번을 앞에 둔 건 순서의 문제**예요. 그냥 물으면 AI가 협조적이라 좋은 말부터 나오고, 거절 이유는 캐물어야 겨우 나옵니다. **먼저 꺼내게 해서 아첨을 구조적으로 막는 것**이지, 부정만 수집하려는 게 아닙니다.

**3번이 "왜 쓰는지"**이고, **4번은 그대로 카피 재료**가 됩니다.

## CLV 네 구간

| 구간 | 신호 |
|---|---|
| **찐팬 후보** | 5O 6O 7O — 낼 수 있고, 또 사고, 데려간다 |
| **반복 고객** | 5O 6O 7X — 오지만 말하지는 않는다 |
| **1회성** | 5O 6X — 한 번 사고 끝 |
| **응원단** | 5X — 마음은 있는데 못 낸다 |

**1회성을 미리 찾아내면 상품 설계가 바뀝니다.**

## 모드 — 이름이 곧 질문입니다

| 모드 | 언제 | 무엇이 나오나 |
|---|---|---|
| **살까, 안 살까** | 기본 검증 | 5명의 반응 + 거절 이유 |
| **한 번인가, 계속인가** | CLV가 궁금할 때 | 4구간 판정 |
| **걸리는데 왜 안 사나** | 광고비가 새는 것 같을 때 | 닮은꼴 6유형 + 처방 |
| **3초 안에 이해되나** | 랜딩·카피 점검 | 의도한 메시지 vs 전달된 메시지 |
| **이 가격이면 사나** | 가격 정할 때 | 지불 의사 + 결정권 |
| **어디서 막히나** | 흐름 점검 | 단계별 통과/이탈 표 |
| **실제로 눌러보면** | URL 있을 때 | 라이브 QA 리포트 |

## 어떤 데이터를 쓰나

[**nvidia/Nemotron-Personas-Korea**](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea) (CC BY 4.0)

- 한국 인구통계에 정렬된 **합성 페르소나 100만 명** · 서술 700만 개
- KOSIS · 대법원 · 국민건강보험공단 · 한국농촌경제연구원 통계에 정렬
- **22세 서울 취준생부터 74세 광주 하역 종사원까지** 실제 인구 분포대로
- 이름·나이·직업은 기본, **가족 구성 · 소비 습관 · 디지털 숙련도 · 말투**까지

### 합성 데이터인 게 왜 나은가

| | 실제 데이터 | **합성 데이터** | AI가 즉석에서 지어낸 것 |
|---|---|---|---|
| 실존 인물 | O | X | X |
| 통계 근거 | O | **O** | X |
| 개인정보 위험 | 높음 | **없음** | 없음 |
| 재현성 | O | **O** | X |

**재현성이 특히 중요합니다.** 오늘 물어본 답과 다음 주에 물어본 답이 같은 근거 위에 서 있어야, *고치고 다시 묻는* 개선 왕복이 성립하니까요.

## 대원칙

1. **가상 검증은 실제 검증의 전 단계입니다.** 진짜 고객을 대체하지 않습니다.
2. **비율로 말하지 않습니다.** 확률 표본이 아니에요.
   ❌ *"40%가 산다"* → ⭕ *"이 조건에서 막히는 사람이 있다"*
   이 스킬은 **몇 %인가**가 아니라 **무엇을 놓쳤는가**에 답합니다.
3. **아첨 금지.** 페르소나는 친구가 아니라 바쁜 생활인입니다.
4. **없는 정보는 지어내지 않습니다.** 카드에 없으면 *"글쎄요, 잘 모르겠는데요"* 가 정답.
5. **소득 필드가 없습니다.** 지불 능력은 소비 서술에서 읽은 **추정**이에요.
6. **한 번에 한 명씩.** 이름표를 붙입니다.
